# Trabajo colaborativo sobre Sistemas Operativos

Git y GitHub son herramientas útiles para colaborar en proyectos de desarrollo de
software. Permiten compartir y sincronizar repositorios de forma eficiente, registrar
los cambios realizados y evitar sobreescrituras accidentales entre colaboradores.

En este trabajo practicaremos la colaboración con Git y GitHub mientras realizamos
un análisis comparativo de los sistemas operativos Windows y Linux.

## Organización de los equipos

La pareja deberá repartirse las tareas de la siguiente manera:

- **Equipo Windows:** analizará el sistema operativo Windows.
- **Equipo Linux:** analizará el sistema operativo Linux.

Al finalizar, cada equipo compartirá sus resultados con el otro para elaborar una
comparación completa de ambos sistemas operativos.
